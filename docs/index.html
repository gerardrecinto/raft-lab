What is implemented

Implemented: leader election with randomized timeouts, log replication, the commit rule that only counts replicas for current-term entries, fast log backtracking, a leader no-op on election, and durable term, vote and log that survive a crash.

Not implemented: snapshots and log compaction, membership changes, read-only queries, a real network or disk.

How it is checked: after every simulated millisecond the simulator verifies election safety, log matching, state machine safety and leader completeness. 150 seeded chaos runs plus 60 heal-and-converge runs pass. A second test removes the vote-time log check and requires the checker to catch the resulting lost committed entry, so the checker is shown to fail when the protocol is broken.
